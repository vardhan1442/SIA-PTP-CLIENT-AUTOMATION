New here? Run the tool on your Windows laptop

The server is plain Python with no Linux-only code, so it runs directly on Windows — no VNC host or SSH tunnel needed. Point it at your existing NFS path and browse straight to localhost.

  1. Install Python and get the code

    Install Python 3 for Windows, then clone the repo in PowerShell.

    git clone https://github.com/vardhan1442/SIA-PTP-CLIENT-AUTOMATION.git $HOME\runDashboard

  2. Start the server with your NFS path

    Point --allow-root at wherever your existing NFS area is reachable from Windows (a mapped network drive or UNC path such as \\server\share\disks) — the same data you already use, just given to the tool.

    cd $HOME\runDashboard; python server.py --port 8765 --allow-root "Z:\site\disks"

    The first start prints a one-time generated admin username and password to the terminal — copy it before it scrolls away.

  3. Open the dashboard

    Browse to http://127.0.0.1:8765/ on the same laptop and sign in with the credentials from step 2.

  4. Secure the account

    Right after first login, come back to this Setup page and change the admin password below, or add your own named admin account and remove the generated one.
